3.4 Finger Tapping — Feature Breakdown

Feature Value What it measures
Tap Rate — Speed (primary score driver). Clinical standard: ≥ 3.0 taps/s = normal.
Mean ITI — Average gap between taps (inter-tap interval). Longer = slower.
ITI Rhythm (CV) — Rhythm consistency. CV > 0.25 flags irregular tapping.
Norm. Amplitude — ADC tap strength vs calibrated baseline. < 60 % = reduced amplitude.
Hesitation Count — Gaps > mean ITI + 2 SD (or 600 ms). ≥ 2 adds a score modifier.

3.6 Pronation-Supination — Feature Breakdown

Feature Value What it measures
Cycle Frequency — Full pro-sup cycles per second (primary driver). Normal ≥ 1.5 Hz.
Peak Angular Velocity — Mean amplitude of each half-swing. Proxy for range of motion.
Cycle Rhythm (CV) — Timing regularity. CV > 0.30 flags rhythm breakdown.
Arrest Count — Stops ≥ 200 ms below deadband (15 dps). ≥ 2 adds a score modifier.
Score scale: 0 Normal 1 Mild 2 Moderate 3 Mod-Severe 4 Severe
